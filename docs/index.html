How to turn this on
About the Power User tier: turning on Custom PHP lets the AI execute any code on your site. We recommend keeping it OFF on live customer sites and turning it ON only on a dev or staging copy. Standard and Full Toolkit are safe on production — every write goes through the Change Ledger with one-click undo.
How it works

From zero to AI-assisted in 3 steps

1

Install one of the AI CLIs

Claude Code, Cursor, Codex, or Gemini — anything that speaks MCP. We provide a single install command for each.

2

Pair your WordPress site

Click "Generate pair token" in the plugin's Setup page. Paste the prompt to your AI. Done in ~60 seconds. No App Password to copy manually.

3

Talk to your AI

Ask in plain English: "Create a landing page", "Fix the slow query on the homepage", "Update Yoast meta on all product pages". Every change is logged + reversible.
